# 架构图说明

图源文件：architecture.mmd。可在支持 Mermaid 的 Markdown 编辑器中渲染，或粘贴到 Mermaid Live Editor 导出 SVG/PNG。图中链上状态与资金核算模块均属于同一个 PredictionMarket 合约，并非多个独立合约。

建议英文图名：System Architecture of the Sepolia Prediction Market

图注：Traders, the owner and a trusted oracle interact with a single PredictionMarket contract through Remix with MetaMask or local Hardhat scripts. The contract stores shares and market state, holds ETH, enforces reserve accounting and emits events. Event outcomes are manually reported by the trusted oracle. The owner and oracle share one account in the deployed demonstration.

用途：报告 Solution Design 的整体架构与角色、链上和链下分工。

事实边界：
- 交易者买入和 owner 提供初始资金时，ETH 随交易转入合约；图中交互箭头包含这些调用。
- 只有买入、卖出和查询脚本具备本次提供的 Sepolia 执行日志；其他角色到 CLI 的连接表示脚本支持的接口，不表示都已经测试。
- 没有数据库、网站前端、后端 API 或自动结果采集服务。
- oracle 的权限检查不保证事件结果真实。
- MarketTestReceiver 是单独的 VM 安全测试工具，不属于生产业务架构，故未画入主图。
- Mermaid 图是逻辑架构，不是部署拓扑或完整业务状态机。
