# 业务流程图说明

图源：market-lifecycle.mmd。

英文图名：Prediction Market Lifecycle and Settlement Paths

英文图注：The owner deploys and funds the market. Before closeTime, traders query prices and submit buy or sell transactions. Trading closes at closeTime. A trusted oracle can report a binary outcome before resolutionDeadline; otherwise, any account can cancel the market after that deadline. Winning holders claim a fixed payout, while users in cancelled markets claim their recorded net deposits. Owner withdrawals preserve outstanding user liabilities.

## 精确边界

- buy/sell：result == 0 且 block.timestamp < closeTime。
- report：result == 0，调用者为 oracle，closeTime <= block.timestamp < resolutionDeadline。
- cancelExpired：result == 0 且 block.timestamp >= resolutionDeadline，任意账户可调用。
- claim：需要已结算或取消且有正数领取权益；获胜领取按份额，取消领取按净投入。
- withdrawSurplus：仅 owner 且 result != 0；可在用户领取前或后进行，必须保留对应负债。
- 时间到达不会自动发送任何交易；report、cancelExpired、claim、withdrawSurplus 都需要有人主动调用。
- 失败方份额不会兑付；取消退款不清除份额显示。图中未展开所有错误分支，详细结果参见 manual-test-results.md。
- report 的输入 0/1 与存储 result 的 1/2 不同，不能混淆。
- 当前未解决盈利卖出限制；价格、时间、权限及资金条件都可能导致交易撤销。
